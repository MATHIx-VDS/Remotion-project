# Remotion-project
projet de création de vidéo avec remotion et Claude 

## Pub Instagram Boxe Académie Brive

- Composition : `BoxeAcademiePromo` (1080×1920, 30 fps, ~28 s) dans `src/BoxePromo.tsx`
- Transitions LED : `src/led.tsx` (mur de LED, balayage néon, néons de plafond, stroboscope, cadre néon)
- Prévisualiser : `npx remotion studio`
- Rendre : `npx remotion render BoxeAcademiePromo out/BoxeAcademie_Instagram.mp4`
